# ISAAD Study Hub

เว็บไซต์ภาษาไทยสำหรับทบทวน **06066304 Information System Analysis and Design, IT KMITL** จากสไลด์ Module 1–6 ที่ใช้ในการติว

## เนื้อหาและแบบทดสอบ

- สรุปเข้ม 6 โมดูล อธิบายหลักการ เหตุผล ตัวอย่าง จุดสับสน และหน้าอ้างอิงในสไลด์
- **10 Minutes Miracle**: หน้าอ่านทวนประมาณ 10 นาที มีแผนเวลา ภาพอธิบาย 6 โมดูล จุดจำ กับดัก และสรุป 30 วินาทีก่อนเข้าห้อง ที่ `#miracle`
- แบบฝึกแยกโมดูล **โมดูลละ 5 ข้อ รวม 30 ข้อ** ตรวจและอธิบายทันที
- คลังข้อสอบรวม **80 ข้อ** แยกจากแบบฝึกแต่ละโมดูล สุ่ม **40 ข้อต่อรอบ** และแก้คำตอบได้ก่อนส่ง
- เฉลยทุกตัวเลือก: ขาว = คำตอบดีที่สุด, เทา = ถูกบางส่วนแต่ไม่ครบโจทย์, ดำ = ผิด
- สรุปคะแนนรายโมดูลและทวนข้อที่พลาด จำความคืบหน้าการอ่านและผลฝึกแยกบทใน localStorage
- เปิดเว็บใหม่ รีเฟรช หรือเริ่มสอบใหม่ จะได้ชุดสุ่มใหม่ คำตอบสอบรวมจึงไม่บันทึกข้ามการเปิดเว็บ
- หยิบข้อที่ยังไม่ถูกสุ่มก่อน เมื่อใช้ครบ 80 ข้อจึงวนคลังใหม่ ไม่มีข้อซ้ำภายในรอบเดียวกัน
- ใช้บนมือถือได้และไม่มีระบบสมัครสมาชิก

ข้อฝึกแต่งเพื่อทบทวนความเข้าใจ **ไม่ใช่ข้อสอบจริงหรือการรับประกันหัวข้อที่จะออกสอบ** คะแนนฝึกไม่ใช่การคาดการณ์คะแนนสอบจริง

## ใช้งานในเครื่อง

เป็น static HTML/CSS/JavaScript ไม่ต้องติดตั้ง dependencies

```sh
python -m http.server 8080
```

เปิด `http://localhost:8080` เบราว์เซอร์ต้องเปิด JavaScript

## ตรวจเนื้อหาและสร้าง data.js

```sh
python scripts/build_data.py
python scripts/build_miracle.py
node --check app.js
node --check data.js
node scripts/test_quiz.cjs
node scripts/test_miracle.cjs
```

ไฟล์ `content/m1-m2.json`, `content/m3-m4.json`, `content/m5-m6.json` เก็บบทเรียนและคำถามชุดเดิม ส่วน `content/exam-extra-m1-m2.json`, `content/exam-extra-m3-m4.json`, `content/exam-extra-m5-m6.json` เพิ่มข้อสอบรวมอีก 40 ข้อ สคริปต์ตรวจจำนวนข้อ จำนวนตัวเลือก คำตอบขาวเพียงหนึ่งตัว ID และ stem ซ้ำ พร้อมรายงานคู่โจทย์ข้ามชุด/คลังที่มีถ้อยคำคล้ายกันใน `content-audit.json` การตรวจความคล้ายเป็นตัวช่วย ไม่แทนการอ่านทบทวนโดยคน

`scripts/test_quiz.cjs` ตรวจการสุ่ม 100 รอบ การให้คะแนน การล็อกคำตอบฝึกหลังเฉลย การแก้คำตอบสอบก่อนส่ง การป้องกันส่งไม่ครบ การกู้ผลฝึก การเริ่มชุดใหม่เมื่อกลับเข้าเว็บ การย้ายประวัติจากรุ่นเก่า และคะแนนรายโมดูล โดยใช้กลไกเดียวกับหน้าเว็บ

คลังข้อสอบรวมกระจาย Module 1–6 เป็น **14 / 14 / 14 / 12 / 12 / 14** ข้อ รวม 80 ข้อ แต่ละรอบสุ่ม **7 / 7 / 7 / 6 / 6 / 7** ข้อ รวม 40 ข้อ แล้วสลับลำดับข้อ จึงครอบคลุมครบทุกโมดูลในทุกรอบ
