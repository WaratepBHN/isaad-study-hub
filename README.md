# ISAAD Study Hub

เว็บไซต์ภาษาไทยสำหรับทบทวน **06066304 Information System Analysis and Design, IT KMITL** จากสไลด์ Module 1–6 ที่ใช้ในการติว

## เนื้อหาและแบบทดสอบ

- สรุปเข้ม 6 โมดูล อธิบายหลักการ เหตุผล ตัวอย่าง จุดสับสน และหน้าอ้างอิงในสไลด์
- แบบฝึกแยกโมดูล **โมดูลละ 5 ข้อ รวม 30 ข้อ** ตรวจและอธิบายทันที
- แบบสอบรวม **40 ข้อ** ใช้โจทย์อีกชุดที่ไม่ซ้ำแบบแยกโมดูล แก้คำตอบได้ก่อนส่ง
- เฉลยทุกตัวเลือก: ขาว = คำตอบดีที่สุด, เทา = ถูกบางส่วนแต่ไม่ครบโจทย์, ดำ = ผิด
- สรุปคะแนนรายโมดูลและทวนข้อที่พลาด พร้อมการจำความคืบหน้าใน localStorage ของเบราว์เซอร์
- ใช้บนมือถือได้และไม่มีระบบสมัครสมาชิก

ข้อฝึกแต่งเพื่อทบทวนความเข้าใจ **ไม่ใช่ข้อสอบจริงหรือการรับประกันหัวข้อที่จะออกสอบ** คะแนนฝึกไม่ใช่การคาดการณ์คะแนนสอบจริง

## ใช้งานในเครื่อง

เป็น static HTML/CSS/JavaScript ไม่ต้องติดตั้ง dependencies

```sh
python -m http.server 8080
```

เปิด `http://localhost:8080` เบราว์เซอร์ต้องเปิด JavaScript

## ตรวจเนื้อหาและสร้าง data.js

```sh
python scripts/build_data.py
node --check app.js
node --check data.js
node scripts/test_quiz.cjs
```

ไฟล์ `content/m1-m2.json`, `content/m3-m4.json`, `content/m5-m6.json` แยกข้อมูลบทเรียนและคำถามสองชุด สคริปต์ตรวจจำนวนข้อ จำนวนตัวเลือก คำตอบขาวเพียงหนึ่งตัว ID และ stem ซ้ำ พร้อมรายงานคู่โจทย์ข้ามชุดที่มีถ้อยคำคล้ายกันใน `content-audit.json` การตรวจความคล้ายเป็นตัวช่วย ไม่แทนการอ่านทบทวนโดยคน

`scripts/test_quiz.cjs` ตรวจการให้คะแนนทุกชุด การล็อกคำตอบฝึกหลังเฉลย การแก้คำตอบสอบก่อนส่ง การป้องกันส่งไม่ครบ การกู้สถานะ และคะแนนรายโมดูล โดยใช้กลไกเดียวกับหน้าเว็บ

ข้อสอบรวมกระจาย Module 1–6 เป็น **7 / 7 / 7 / 6 / 6 / 7** ข้อ รวม 40 ข้อ และสลับโมดูลในลำดับการทำ
