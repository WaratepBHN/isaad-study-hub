# ISAAD Study Hub

เว็บไซต์ภาษาไทยสำหรับทบทวน **06066304 Information System Analysis and Design, IT KMITL** มีสรุป Module 1–6 และแบบทดสอบจากสไลด์ Module 1–13 ที่ใช้ในการติว

## เนื้อหาและแบบทดสอบ

- สรุปเข้ม 6 โมดูล อธิบายหลักการ เหตุผล ตัวอย่าง จุดสับสน และหน้าอ้างอิงในสไลด์
- **10 Minutes Miracle**: หน้าอ่านทวนประมาณ 10 นาที มีแผนเวลา ภาพอธิบาย 6 โมดูล จุดจำ กับดัก และสรุป 30 วินาทีก่อนเข้าห้อง ที่ `#miracle`
- แบบฝึกแยกโมดูล **โมดูลละ 5 ข้อ รวม 30 ข้อ** ตรวจและอธิบายทันที
- คลังข้อสอบรวม **80 ข้อ** แยกจากแบบฝึกแต่ละโมดูล สุ่ม **40 ข้อต่อรอบ** และแก้คำตอบได้ก่อนส่ง
- เฉลยทุกตัวเลือก: ขาว = คำตอบดีที่สุด, เทา = ถูกบางส่วนแต่ไม่ครบโจทย์, ดำ = ผิด
- สรุปคะแนนรายโมดูลและทวนข้อที่พลาด จำความคืบหน้าการอ่านและผลฝึกแยกบทใน localStorage
- เปิดเว็บใหม่ รีเฟรช หรือเริ่มสอบใหม่ จะได้ชุดสุ่มใหม่ คำตอบสอบรวมจึงไม่บันทึกข้ามการเปิดเว็บ
- หยิบข้อที่ยังไม่ถูกสุ่มก่อน เมื่อใช้ครบ 80 ข้อจึงวนคลังใหม่ ไม่มีข้อซ้ำภายในรอบเดียวกัน
- ใช้บนมือถือได้และไม่มีระบบสมัครสมาชิก

## แบบทดสอบ Module 7–13 · 30 ข้อ

เปิดที่ https://waratepbhn.github.io/isaad-study-hub/#exam-7-13 หรือเมนู **สอบ 7–13 · 30**

- ชุดใหม่ 30 ข้อ: Module 7/8/9/10/11/12/13 จำนวน **4/4/4/4/4/5/5** ข้อ เน้นการประยุกต์และแยกแนวคิดทางเทคนิคที่ใกล้เคียง
- แสดงทีละข้อ เลือกและย้อนแก้ได้ก่อนส่ง ต้องตอบครบจึงตรวจคะแนน แสดงผลรายโมดูล พร้อมเหตุผลและหน้าสไลด์ของทุกตัวเลือกหลังส่ง
- ทุกครั้งที่เริ่มใหม่หรือเปิดหน้าใหม่ ใช้คำถามชุด 30 ข้อนี้โดยสลับทั้งลำดับข้อและตัวเลือก ตำแหน่งคำตอบดีที่สุดกระจาย 7–8 ข้อต่อตัวอักษรต่อรอบ
- การสลับย้ายตัวเลือก เฉลย สี และเหตุผลไปด้วยกัน คำตอบอยู่ในหน่วยความจำของการเปิดเว็บครั้งนั้น การเปิดใหม่และ BFCache reentry เริ่มใหม่ ส่วนการเปลี่ยนหน้าในเว็บเดียวกันยังกลับมาทำต่อได้
- ผู้เขียนและผู้ตรวจไขว้ตรวจโจทย์กับสไลด์ แก้ตัวเลือกเทาที่กำกวมหรือผิดเงื่อนไข และลดใบ้จากจำนวนรายละเอียด ความยาว และคำผิดแบบเห็นชัด
- `exam-7-13-audit.json` รายงานความยาวรายตัวเลือก อัตราส่วนยาว/สั้น และคะแนนคาดหมายของกลยุทธ์เลือกข้อยาวหรือสั้นที่สุด การวัดตัวอักษรเป็นตัวช่วยตรวจใบ้ ต้องใช้ร่วมกับการตรวจเนื้อหา

ไฟล์คำถามอยู่ใน `content/exam-7-13-m7-m8.json`, `content/exam-7-13-m9-m10.json`, `content/exam-7-13-m11-m13.json` แล้วสร้าง payload ด้วย `scripts/build_exam_7_13.py` สคริปต์ตรวจ schema, จำนวนข้อ, สี/เฉลย, หน้าอ้างอิง, ID/stem ซ้ำ, อัตราส่วนความยาวไม่เกิน 1.45 และเหตุผลที่ไม่อ้างตัวอักษร A–D เพื่อรองรับการสลับช้อยส์

ข้อฝึกแต่งเพื่อทบทวนความเข้าใจ **ไม่ใช่ข้อสอบจริงหรือการรับประกันหัวข้อที่จะออกสอบ** คะแนนฝึกไม่ใช่การคาดการณ์คะแนนสอบจริง

## ใช้งานในเครื่อง

เป็น static HTML/CSS/JavaScript ไม่ต้องติดตั้ง dependencies

```sh
python -m http.server 8080
```

เปิด `http://localhost:8080` เบราว์เซอร์ต้องเปิด JavaScript

## ตรวจเนื้อหาและสร้าง data.js

```sh
python scripts/build_data.py
python scripts/build_miracle.py
python scripts/build_exam_7_13.py
node --check app.js
node --check data.js
node scripts/test_quiz.cjs
node scripts/test_miracle.cjs
node scripts/test_exam_7_13.cjs
```

ไฟล์ `content/m1-m2.json`, `content/m3-m4.json`, `content/m5-m6.json` เก็บบทเรียนและคำถามชุดเดิม ส่วน `content/exam-extra-m1-m2.json`, `content/exam-extra-m3-m4.json`, `content/exam-extra-m5-m6.json` เพิ่มข้อสอบรวมอีก 40 ข้อ สคริปต์ตรวจจำนวนข้อ จำนวนตัวเลือก คำตอบขาวเพียงหนึ่งตัว ID และ stem ซ้ำ พร้อมรายงานคู่โจทย์ข้ามชุด/คลังที่มีถ้อยคำคล้ายกันใน `content-audit.json` การตรวจความคล้ายเป็นตัวช่วย ไม่แทนการอ่านทบทวนโดยคน

`scripts/test_quiz.cjs` ตรวจการสุ่ม 100 รอบ การให้คะแนน การล็อกคำตอบฝึกหลังเฉลย การแก้คำตอบสอบก่อนส่ง การป้องกันส่งไม่ครบ การกู้ผลฝึก การเริ่มชุดใหม่เมื่อกลับเข้าเว็บ การย้ายประวัติจากรุ่นเก่า และคะแนนรายโมดูล โดยใช้กลไกเดียวกับหน้าเว็บ

`scripts/test_exam_7_13.cjs` ตรวจการสลับข้อ/ช้อยส์ 100 รอบและความตรงของเฉลยทุกช่อง รวมถึง event flow ของหน้าเว็บผ่าน DOM จำลองใน Node: ทำครบ 30 ข้อโดยจงใจเลือกเทา/ดำสองข้อได้ 28/30, ย้อนแก้, ส่งไม่ครบ, ล็อกหลังส่ง, filters, focus, การกลับเข้าเว็บ, route เดิม และการ escape ข้อความ การจำลองนี้ไม่แทนการตรวจภาพหน้าจอในเบราว์เซอร์

คลังข้อสอบรวมกระจาย Module 1–6 เป็น **14 / 14 / 14 / 12 / 12 / 14** ข้อ รวม 80 ข้อ แต่ละรอบสุ่ม **7 / 7 / 7 / 6 / 6 / 7** ข้อ รวม 40 ข้อ แล้วสลับลำดับข้อ จึงครอบคลุมครบทุกโมดูลในทุกรอบ
